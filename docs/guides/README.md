# Guides for day-to-day use

Guides are short, task-based pages written for the person doing the task: "How to book a Monthly Maintenance series", not "The scheduling module". Each one is written when the feature it describes is built, in the same pull request, with `status: current`. Until then this page lists it as planned.

Running the server itself (deploying, backups, monitoring) is covered in [../operations/](../operations/deploying-changes.md), not here.
